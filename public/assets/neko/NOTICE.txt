Neko cursor companion

The project credits the classic Neko sprites and uses the oneko 8-by-4
sprite-sheet layout. The portfolio's browser animation controller is a
TypeScript implementation based on the project's documented sprite positions
and chase / idle / grooming / sleep behavior. No Go binary is shipped or run.
